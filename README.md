## Описание

**Hexlet Chat** — это упрощенная версия Slack Chat, учебный проект, разработанный в рамках курса Hexlet. Это React/Redux приложение, работающее в режиме реального времени.

### Основные возможности:

-  Общение в реальном времени через WebSocket
-  Взаимодействие с REST API
-  React с использованием хуков
-  Redux Toolkit для управления состоянием
-  Маршрутизация на стороне клиента (React Router)
-  Авторизация и аутентификация (JWT)
-  Сборка и развертывание (Vite)

##  Минимальные требования

- **Node.js:** версия 16 или выше 

## Быстрый старт

###  Клонировать репозиторий

git clone git@github.com:Ivan-ObiWan/frontend-project-12.git

### Установить зависимости

make install

### Собрать проект

make build

### Запустить сервер

make start
